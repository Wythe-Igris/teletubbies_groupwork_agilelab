# Teletubbies Group Work — Agile Lab

## About the Project

**IMAGINARY** is an AI student-life assistant for international university students in Thailand. The responsive web application will help students ask questions in simple English, summarize university notices and find useful Thai phrases for everyday situations.

This repository contains our Agile project documentation, including the project charter, requirements, acceptance criteria and database design.
